# pink-world--ai Generation Experiment

welcome to my very first project created using generative AI!

##🤖 what is this?
I wanted to test the capabilities of promt-to-desing AI features.I provided the text promt asking for cute pink theme,specific animation style,and a soft sound after clicked in background.the AI interpreted my prompt and built this interactive presentation completely by itself!✨
